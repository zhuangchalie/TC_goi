# GuardianAI — 60-second pitch

**Problem:** Scam SMS and social-engineering calls are designed to create panic:
OTP requests, fake banks, fake authorities, urgent payments and phishing links.

**Solution:** GuardianAI sits between the event and the user's decision. It
scores the risk, explains the signals, and interrupts the scam with an immediate
warning.

**Technology:** Android native event capture + explainable local detection +
OpenVINO-ready Intel edge inference + modular reputation layer.

**Why it matters:** Fast, explainable, privacy-first and designed to degrade
gracefully offline.

**Honest limitation:** A competition prototype must distinguish implemented
features from planned ML training. We do not claim benchmark accuracy until a
real labeled dataset has been evaluated.
