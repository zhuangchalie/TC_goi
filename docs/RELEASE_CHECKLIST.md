# Release checklist — competition

- [ ] Build on a real Android phone.
- [ ] Grant SMS + notification permissions.
- [ ] Test incoming SMS with 5 benign and 10 scam-like samples.
- [ ] Verify notification appears while app is backgrounded.
- [ ] Test manual Scan screen.
- [ ] Verify history and clear-history.
- [ ] Demonstrate privacy screen.
- [ ] Do not claim ML accuracy until a trained model is benchmarked.
- [ ] If using OpenVINO, record device, model version, latency and metrics.
- [ ] Prepare one slide on Android/iOS capability differences.
